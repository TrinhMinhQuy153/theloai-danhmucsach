# THƯ VIỆN MINI

## 1. Giới thiệu

THƯ VIỆN MINI là website quản lý thư viện được xây dựng bằng PHP và MySQL.

Hệ thống hỗ trợ quản lý và hiển thị thông tin sách, thể loại và danh mục sách.

## 2. Công nghệ sử dụng

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- Git & GitHub

## 3. Chức năng đã thực hiện

### Quản lý sách
- Hiển thị danh sách sách
- Thêm sách
- Sửa thông tin sách
- Xóa sách

### Quản lý thể loại
- Hiển thị danh sách thể loại
- Thêm thể loại
- Sửa thể loại
- Xóa thể loại

### Quản lý danh mục
- Quản lý danh mục sách
- Hiển thị thông tin danh mục

5. Cài đặt
Bước 1
Cài đặt XAMPP và bật Apache, MySQL.
Bước 2
Đặt thư mục project vào:
C:\xampp\htdocs\THUVIENMINI
Bước 3
Tạo database MySQL theo cấu trúc của project.
Bước 4
Cấu hình kết nối database trong file:
config/database.php
File config/database.php không được đưa lên GitHub để bảo vệ thông tin đăng nhập database.

Bước 5
Truy cập website:
http://localhost/THUVIENMINI/
